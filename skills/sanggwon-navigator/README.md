# 상권 내비게이터 (sanggwon-navigator)

> 2026 제1회 Upstage × BDAI Harness Engineering Skillthon 제출작
> **"여기서 얼마 벌고 · 얼마 나가고 · 얼마 받을 수 있나"를 한 장으로.**

```bash
python scripts/make_report.py --region 성수동 --biz 카페
```

## 1. 문제 정의

### 관찰

창업하려는 사람이 알아야 할 세 가지가 **세 곳에 흩어져 있다.**

| 알아야 할 것 | 어디에 있나 | 나머지 둘은? |
|---|---|---|
| 여기서 얼마 버나 | 서울시 상권분석, 소상공인365 | 임대료·정책 없음 |
| 얼마가 나가나 | 부동산 플랫폼, 부동산원 통계 | 매출·정책 없음 |
| 얼마를 받을 수 있나 | 기업마당, 소상공인365 | 매출·임대료 없음 |

소상공인365는 상권분석과 정책정보를 한 포털에 두지만 **별도 메뉴**일 뿐,
"이 상권·이 업종·이 조건이면 → 이 제도"로 이어주지 않는다.
결국 세 곳을 따로 돌며 스스로 연결해야 하고, 대부분은 자기가 받을 수 있는 제도를 모른 채 시작한다.

### 가설

> 필요한 것은 더 많은 정보가 아니라 **연결된 판단**이다.
> 매출과 임대료를 나눠본 값 하나가, 매출 순위 100개보다 결정에 도움이 된다.

### 분석 질문

1. 특정 지역·업종의 창업 적합도를 **재현 가능한 방식**으로 등급화할 수 있는가?
2. 매출이 좋은 상권과 **실제로 남는 상권**은 얼마나 다른가?
3. 해당 지역·조건에서 **오늘 신청 가능한** 지원제도를 자동으로 골라낼 수 있는가?
4. 사용자에게 **되묻지 않고** 조건별 결과를 모두 제시할 수 있는가?

### 이 질문이 실제 데이터에서 어떻게 답해지나

성수동 카페 상권. 임대료는 **모두 월 384만원으로 같다**(같은 뚝섬 상권, 60.2㎡ 기준).
그런데 매출이 달라서 부담률이 **16%에서 41%까지** 벌어진다.

| 상권 | 상권력 | 점포당 월매출 | 임대료 부담률 | 처방 |
|---|---|---|---|---|
| 성수역 | B | 2,410만원 | **16%** | 🟢 노려라 |
| 뚝섬역 | B | 1,978만원 | **19%** | 🟢 노려라 |
| 성수초등학교 | **A** | 1,281만원 | **30%** | 🟡 자금력 싸움 |
| 성수동카페거리 | **A** | 1,054만원 | **36%** | 🟡 자금력 싸움 |
| 뚝섬역상점가 | D | 927만원 | **41%** | 🔴 피하라 |

**성수초등학교·성수동카페거리는 상권력 A인데 자금력 싸움으로 분류된다.**
커피 전문점의 손익분기 임대료율은 21.3%인데 30%·36%를 내고 있어,
평균 원가구조로는 이미 적자 구간이다. 등급이 하나였다면 절대 보이지 않았을 정보다.

## 2. 설계 원칙

**① 조건은 필터가 아니라 분기다.**
나이·성별·창업경력을 묻지 않는다. 조건별로 갈라서 전부 보여준다.
→ 답이 없어도 리포트가 완결되므로 **사람 개입 없이 돈다.**

**② 등급을 하나로 합치지 않는다.**
상권력(장사가 되는가)과 진입비용(얼마가 드는가)을 따로 낸다.
합치면 "매출이 좋아서 B"인지 "월세가 싸서 B"인지 구분이 사라진다.

**③ 판단 기준을 코드가 아니라 문서에 둔다.**
가중치·컷오프·업종 매핑·정책 키워드가 전부 `config/` 와 `reference/` 에 있다.
스크립트는 거기서 읽는다. 이것이 Prompt가 아니라 Skill인 이유다.

**④ 데이터마다 시계가 다르다.**
상권·임대료는 분기마다 갱신되므로 캐시하고 스탬프를 박는다.
지원제도는 마감일이 매일 바뀌므로 캐시하지 않는다.

## 6. 어떻게 판정하나

### 축 1 — 상권력 (A~E)

파생지표 5종을 서울 전체 같은 업종 상권 분포 대비 백분위로 환산해 가중합한다.

| 지표 | 가중치 | 잡아내는 것 |
|---|---|---|
| 매출 성장률 (전년 동분기) | 0.25 | 지금 뜨고 있는가 |
| 유동인구 대비 매출 전환율 | 0.20 | 사람은 많은데 돈은 안 쓰는 상권 |
| 경쟁 밀도 (역방향) | 0.20 | 파이를 몇이 나눠 먹는가 |
| 생존 신호 (개업률 − 폐업률) | 0.25 | 들어와서 버티는가 |
| 상권 라이프사이클 | 0.10 | 위 넷과 어긋나지 않는지 |

**허수를 막는 장치 둘** — 점포 3개 미만은 등급을 내지 않고,
전년 매출이 업종 중앙값의 절반 미만이면 성장률을 산출하지 않는다.
(없으면 전년 300만원 → 올해 4,600만원인 상권이 성장률 1601%로 서울 1위가 된다)

### 축 2 — 진입비용 (저 / 중 / 고)

```
임대료 부담률 = (부동산원 ㎡당 임대료 × 60.2㎡) ÷ 점포당 월평균 매출
```

절대 금액이 아니라 비율로 본다. 비싼 동네가 비싼 만큼 벌어주면 문제가 아니기 때문이다.
60.2㎡는 서울시가 1층 점포 12,531개를 실측한 평균 전용면적이다.

**구간 경계에 근거가 있다.**

| 경계 | 값 | 출처 |
|---|---|---|
| 저 / 중 | **16%** | 서울 145개 주요상권 실측 평균 (서울시 2023 상가임대차 실태조사) |
| 중 / 고 | **업종별 손익분기** | 100% − 임대료제외 원가율 (커피 21.3% · 치킨 14.8%) |

**공실률은 등급에 넣지 않는다** — 임차인에게 공실률이 높은 것은 나쁜 소식이 아니라 협상 여지다.

### 월 수익 추정 — 외식업 10종

KREI 「외식업체 경영실태 조사」는 임차료를 **별도 항목**으로 조사한다.
그래서 그 칸만 우리 실측 임대료로 갈아끼우면 보정 없이 영업이익이 나온다.

```
월 영업이익 = 매출 × (100% − 임대료제외 원가율 − 실제 임대료율)
```

국세청 경비율로 같은 값을 계산하면 커피 손익분기 21.0%로, KREI 기준 21.3%와 0.3%p 차이다.
세제 자료와 경영실태 조사라는 독립된 두 출처가 같은 값을 가리킨다.

> 서비스업·소매업은 이 조사 대상이 아니므로 **영업이익을 산출하지 않는다.**
> 없는 숫자를 지어내지 않고 임대료 부담률까지만 낸다.

### 두 축을 조합해 처방

|  | 비용 낮음 | 비용 높음 |
|---|---|---|
| **상권력 높음** | 🟢 노려라 | 🟡 자금력 싸움 |
| **상권력 낮음** | 🔵 저리스크 실험 | 🔴 피하라 |

숫자의 근거는 [`reference/scoring_rules.md`](reference/scoring_rules.md).

## 7. 한계

- 매출은 **카드 데이터 기반 추정치**이며 현금 거래가 반영되지 않는다.
- 임대료는 부동산원 상권 59개 단위다. 같은 상권 안에서는 동일한 값이 적용된다.
  (부담률은 매출이 분모라 상권별로 달라진다)
- **부동산원은 주요 상권만 조사한다.** 골목 안쪽 점포는 조사 대상이 아니어서,
  인근 주요상권 시세를 적용하면 부담률이 과대 산정된다.
  부담률 50%를 넘으면 **진입비용을 판정하지 않고** 상권력만 제시한다.
  (발달상권 83% · 골목상권 33%가 정상 판정된다)
- 부동산원 상권이 없는 자치구(도봉구)는 서울 주요상권 평균으로 대체한다. **커버리지 98.4%.**
- **개별 매물이나 공실 위치는 제공하지 않는다.** 공공데이터에 없다.
- 보증금은 공공데이터로 확인할 수 없다. 권리금은 서울 시도 단위 업종 평균만 제공한다.
- 서울 외 지역은 상권 등급을 낼 수 없다. 지원제도 매칭만 제공한다.
- 지원제도는 공고 키워드로 분류한 것이며, **최종 자격은 공고문 확인이 필요하다.**

### 전국 확장에 대하여

정책 매칭 레이어는 기업마당 기반이라 **이미 전국 대응**이고,
임대료 레이어도 부동산원 전국 276개 상권을 그대로 쓸 수 있다.
상권 진단 레이어만 지역별 데이터 어댑터를 추가하면 된다.

`reference/scoring_rules.md` 에 **"백분위 모집단은 지역 단위로 산정한다"** 를 명시해,
전국 확장 시 서울이 분포를 지배해 지방 상권이 하위 등급으로 몰리는 왜곡을 막는다.

서울을 레퍼런스 구현으로 삼은 이유는 **데이터 밀도**다.
전국 단위 상가 데이터에는 매출이 없어, 넓히면 지표가 축소되고 등급이 무의미해진다.
